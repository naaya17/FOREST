### Technique name:
Cloud Data Collection via Request (T1023)

### Description:
Collects user-related data from cloud services by issuing direct HTTP requests to public, internal, or undocumented API endpoints used by official client applications.

### Synonyms:
Cloud Data Collection via Internal API, Cloud Data Collection via RESTful API

### Details:
This technique collects user-related cloud data by capturing, analyzing, or emulating API request traffic generated by client applications. Requests may target public or undocumented endpoints identified via network observation or reverse engineering. Returned responses may include artifacts such as messages, file metadata, activity logs, and identity attributes. Analysts may use traffic capture tools or instrumentation to extract and store this data for forensic or intelligence purposes, both reactively and proactively.

### Examples:
Magnet AXIOM, Oxygen Cloud Extractor, Cellebrite UFED CLOUD
